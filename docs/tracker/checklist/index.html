Tasks for Physical AI & Humanoid Robotics

Feature Name: Physical AI & Humanoid Robotics​

Dependencies:​

  • This tasks list is dependent on the spec.md (specs/001-physical-ai-spec/spec.md) and plan.md (specs/001-physical-ai-spec/plan.md) being finalized.

Implementation Strategy:​

  • The implementation will follow a phased approach as outlined below, from foundational environment setup to advanced perception and control.
  • Tasks are organized by phase, with a logical flow. Parallelization opportunities are marked with [P].

Phase 0: The Iron Foundation (Weeks 0-1)​

Goal: Establish the compute infrastructure before software deployment. Deliverable: A dual-environment setup (Workstation + Edge) communicating over SSH.

Workstation Setup ("The Digital Twin")​

  • T001 OS Installation: Perform clean install of Ubuntu 22.04 LTS on the workstation. (Workstation Setup)
  • T002 Verification: Ensure "Safe Graphics" mode was not used during OS install. (Workstation Setup)
  • T003 Driver Stack: Install NVIDIA Driver 535.xx (via Software & Updates > Additional Drivers). (Workstation Setup)
  • T004 Driver Stack: Install CUDA 12.2 Toolkit. (Workstation Setup)
  • T005 Verification: Run nvidia-smi to confirm GPU visibility. (Workstation Setup)
  • T006 Simulation Core: Install Omniverse Launcher. (Workstation Setup)
  • T007 Simulation Core: Download Isaac Sim 2023.1.1 (or latest 4.x if compatible with provided assets). (Workstation Setup)
  • T008 Simulation Core: Run ./isaac-sim.sh to trigger initial shader caching (Expect 10-15 min wait time on first launch). (Workstation Setup)

Edge Kit Setup ("The Physical Brain")​

  • T009 Flashing: Flash JetPack 6.0 to the NVMe SSD of the Jetson Orin Nano. (Edge Kit Setup)
  • T010 Flashing: Confirm Ubuntu 22.04 environment is active after flashing. (Edge Kit Setup)
  • T011 Network Configuration: Assign a Static IP (e.g., 192.168.1.100) to the Jetson. (Edge Kit Setup)
  • T012 Network Configuration: Update /etc/hosts on Workstation with Jetson's IP. (Workstation Setup)
  • T013 Network Configuration: Update /etc/hosts on Jetson with Workstation's IP. (Edge Kit Setup)
  • T014 Verification: SSH from Workstation to Jetson without password prompt (optional: set up keys). (Workstation/Edge Kit Setup)

Phase 1: The Nervous System (Weeks 2-5)​

Goal: Enable communication between software nodes and physics engines. Deliverable: A robot model spawned in simulation reachable by ROS 2 topics.

Middleware Installation (Both Machines)​

  • T015 ROS 2 Humble: Run sudo apt install ros-humble-desktop on Workstation. (Workstation Setup)
  • T016 ROS 2 Humble: Run sudo apt install ros-humble-desktop on Jetson. (Edge Kit Setup)
  • T017 Environment Config: Add source /opt/ros/humble/setup.bash to ~/.bashrc (Both). (Workstation/Edge Kit Setup)
  • T018 Environment Config: Set export ROS_DOMAIN_ID=42 (or assigned Student ID) in ~/.bashrc (Both). (Workstation/Edge Kit Setup)
  • T019 Build tools: Run sudo apt install python3-colcon-common-extensions. (Workstation/Edge Kit Setup)

Workspace Overlay​

  • T020 Directory Setup: Create ~/physical_ai_ws/src. (Workstation/Edge Kit Setup)
  • T021 Directory Setup: Run colcon build to generate build/ and install/ folders. (Workstation/Edge Kit Setup)
  • T022 Assets: Clone course repository into src/. (Workstation Setup)
  • T023 Assets: Import Humanoid USD files into Isaac Sim. (Workstation Setup)
  • T024 Verification: Spawn robot in empty Isaac Sim stage. (Workstation Setup)

Phase 2: Perception & Control (Weeks 6-10)​

Goal: Give the robot eyes and the ability to move. Deliverable: A robot that detects objects and walks to them in simulation.

Visual SLAM (VSLAM)​

  • T025 Installation: Install NVIDIA Isaac ROS GEMs on Workstation. (Workstation Setup)
  • T026 Installation: Install NVIDIA Isaac ROS GEMs on Jetson. (Edge Kit Setup)
  • T027 Deployment: Deploy isaac_ros_visual_slam node. (Workstation/Edge Kit Setup)
  • T028 Sensor Bridge: Enable the "ROS 2 Bridge" extension in Isaac Sim. (Workstation Setup)
  • T029 Sensor Bridge: Map the Simulated Camera USD output to the /camera/color/image_raw ROS topic. (Workstation Setup)

Navigation (Nav2)​

  • T030 Mapping: Teleoperate robot in Sim to generate 2D Occupancy Grid. (Workstation Setup)
  • T031 Mapping: Save map using ros2 run nav2_map_server map_saver_cli. (Workstation Setup)
  • T032 Planning: Launch nav2_bringup. (Workstation Setup)
  • T033 Planning: Tune the costmaps (inflation radius) to account for the humanoid's arm span. (Workstation Setup)
  • T034 Verification: Send "2D Goal Pose" in RViz and confirm robot moves. (Workstation Setup)

Phase 3: Embodied Intelligence (Weeks 11-12)​

Goal: Integrate the LLM "Brain" to command the "Body." Deliverable: Voice-commanded autonomy.

VLA Integration​

  • T035 Voice Interface: Install openai-whisper on Jetson. (Edge Kit Setup)
  • T036 Voice Interface: Test microphone input with tiny.en or base.en model for latency. (Edge Kit Setup)
  • T037 Cognitive Node: Deploy Python "Cognitive Node" (LLM Planner). (Edge Kit Setup)
  • T038 Cognitive Node: Connect Whisper output string to Cognitive Node input. (Edge Kit Setup)
  • T039 System Test: Issue command: "Go to the kitchen and find the apple." (Workstation/Edge Kit Setup)
  • T040 Verification: Check logs for transformation: Maps_to(kitchen) -> detect_object(apple). (Workstation/Edge Kit Setup)

Phase 4: Sim-to-Real Transfer (Week 13)​

Goal: Deploy code from the RTX Workstation to the Jetson Orin. Deliverable: Capstone Demo.

The Reality Gap​

  • T041 Hardware Calibration: Calibrate the physical RealSense camera. (Physical Hardware)
  • T042 Hardware Calibration: Update URDF xacro with real-world mounting offsets. (Physical Hardware)
  • T043 Safety: Configure velocity_smoother to limit acceleration. (Physical Hardware)
  • T044 Safety: Verify Emergency Stop (E-Stop) functionality. (Physical Hardware)
  • T045 Deployment: Copy the install/ folder from Workstation to Jetson (or recompile on Jetson). (Workstation/Edge Kit Setup)
  • T046 Deployment: Run the robot_bringup.launch.py. (Edge Kit Setup)
  • T047 Final Verification: Execute full VLA pipeline on physical hardware. (Physical Hardware)

Troubleshooting Matrix​

This section is informational and does not contain actionable tasks.

SymptomProbable CauseFix
Sim runs at <10 FPSRay Tracing disabledCheck nvidia-smi; Ensure PSU is powering GPU.
ROS Topics not visibleMulticast blockedCheck ufw status (Firewall); Verify ROS_DOMAIN_ID matches.
Robot falls instantlyPID Gains too highLower P-gain in ros2_control configuration by 50%.
Jetson overheatsFan mode silentRun sudo jetson_clocks --fan to maximize cooling.
