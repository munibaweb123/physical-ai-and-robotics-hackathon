# Core Objectives

By the end of this course, you will be able to:

1. **Understand Physical AI Principles**: Explain the difference between digital and embodied intelligence.
2. **Master ROS 2**: Build and deploy packages using Nodes, Topics, and Services in ROS 2 (Humble).
3. **Simulate with Fidelity**: Create Digital Twins using URDFs in Gazebo and NVIDIA Isaac Sim.
4. **Develop with Isaac Platform**: Utilize NVIDIA's AI robotics stack for perception and control.
5. **Design Humanoid Controls**: Implement bipedal locomotion and manipulation strategies.
6. **Integrate Conversational AI**: Bridge Large Language Models (GPT) with robot actions (VLA) for natural interaction.
