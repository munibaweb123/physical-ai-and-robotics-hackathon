# ضمیمہ A: کلاؤڈ لیب سیٹ اپ

یہ ضمیمہ ایک مضبوط کلاؤڈ بیسڈ لیب ماحول کے قیام کے لئے تفصیلی رہنما فراہم کرتا ہے، خاص طور پر AWS g5.2xlarge انسٹینسز پر توجہ مرکوز کرتے ہوئے۔ فزیکل AI اور ہیومینائیڈ روبوٹکس کے میدان میں، مقامی ہارڈویئر کی حدود اکثر بڑے ماڈلز کی تربیت، پیچیدہ سیمولیشنز چلانے، یا اعلیٰ معیار کے سینسری ڈیٹا کے تجربات کے لئے رکاوٹ بن سکتی ہیں۔ کلاؤڈ بیسڈ ورک سٹیشنز ایک قابل پیمائش اور طاقتور متبادل پیش کرتے ہیں، جو جدید GPUs اور کافی کمپیوٹیشنل وسائل تک رسائی فراہم کرتے ہیں۔ یہ ہدایات آپ کو ایک طاقتور ریموٹ ورک سٹیشن ترتیب دینے میں مدد کریں گی جو آپ کے مقامی ترقیاتی فلو کے ساتھ بغیر کسی رکاوٹ کے ضم ہو سکتا ہے، جس سے آپ کو زیادہ مطالبہ کرنے والے AI اور روبوٹکس پروجیکٹس کو بغیر کسی اہم ابتدائی ہارڈویئر سرمایہ کاری کے نمٹنے کے قابل بناتا ہے۔

### کلاؤڈ لیب ماحول کیوں منتخب کریں؟

فزیکل AI کی ترقی کے لئے کلاؤڈ لیبز کئی قائل کرنے والے فوائد پیش کرتے ہیں:

*   **قابل پیمائش:** اپنے پروجیکٹ کی ضروریات کے مطابق اپنے کمپیوٹیشنل وسائل کو آسانی سے بڑھائیں یا کم کریں، ترقی کے لئے ایک واحد GPU انسٹینس سے لے کر تقسیم شدہ تربیت کے لئے متعدد GPU انسٹینسز تک۔
*   **لاگت کی مؤثریت:** پے-ایز-یو-گو ماڈلز کا مطلب ہے کہ آپ صرف ان وسائل کی ادائیگی کرتے ہیں جو آپ استعمال کرتے ہیں، ہارڈویئر میں بڑے ابتدائی سرمایہ کاری سے بچتے ہیں جو ممکنہ طور پر متروک ہو سکتے ہیں۔
*   **رسائی:** کہیں سے بھی انٹرنیٹ کنکشن کے ساتھ اپنے طاقتور ترقیاتی ماحول تک رسائی حاصل کریں، لچکدار کام کے انتظامات کو فروغ دیتے ہیں۔
*   **پری کنفیگرڈ ماحول:** بہت سے کلاؤڈ فراہم کنندگان مشہور AI اور روبوٹکس فریم ورک (CUDA، cuDNN، TensorFlow، PyTorch، ROS) کے ساتھ پہلے سے تیار شدہ امیجز پیش کرتے ہیں، جو سیٹ اپ کے وقت کو نمایاں طور پر کم کرتے ہیں۔
*   **تعاون:** کلاؤڈ ماحول ٹیم کے اراکین کے درمیان آسان تعاون کی سہولت فراہم کرتے ہیں، کیونکہ ہر کوئی ایک ہی طاقتور انفراسٹرکچر پر مستقل کنفیگریشنز کے ساتھ کام کر سکتا ہے۔

### AWS g5.2xlarge انسٹینس: ایک تجویز کردہ انتخاب

AWS g5.2xlarge انسٹینس ایک کلاؤڈ بیسڈ فزیکل AI لیب کے لئے ایک بہترین انتخاب ہے، اس کی طاقتور GPU صلاحیتوں اور لاگت کی مؤثریت کے توازن کی وجہ سے۔ اس میں شامل ہیں:

*   **GPU:** ایک NVIDIA A10G ٹینسر کور GPU، جو ڈیپ لرننگ تربیت، انفرنس، اور کمپیوٹ-انٹینسیو سیمولیشنز کے لئے نمایاں تیز رفتاری فراہم کرتا ہے۔
*   **vCPUs:** 8 ورچوئل CPUs، جو عام کاموں اور ڈیٹا آرکیسٹریشن کے لئے کافی پروسیسنگ پاور فراہم کرتے ہیں۔
*   **میموری:** 32 GiB RAM، درمیانے سے بڑے پیمانے کے AI ماڈلز اور ڈیٹا سیٹس کے لئے موزوں۔
*   **نیٹ ورک کی کارکردگی:** 10 گیگابٹ تک نیٹ ورک بینڈوڈتھ، اسٹوریج سے اور اسٹوریج تک تیز ڈیٹا ٹرانسفر کو یقینی بناتی ہے۔
*   **اسٹوریج:** EBS-بیکڈ اسٹوریج، جو I/O مطالبات کو پورا کرنے کے لئے ہائی پرفارمنس SSDs کے لئے کنفیگر کیا جا سکتا ہے۔

### مرحلہ وار سیٹ اپ گائیڈ

#### 1. AWS اکاؤنٹ سیٹ اپ اور ریجن کا انتخاب

اگر آپ کے پاس نہیں ہے، تو ایک AWS اکاؤنٹ بنائیں۔ یقینی بنائیں کہ آپ ایک ایسا ریجن منتخب کرتے ہیں جو g5 انسٹینسز پیش کرتا ہے اور آپ یا آپ کے ڈیٹا سورسز کے قریب جغرافیائی طور پر واقع ہے تاکہ لیٹنسی کو کم کیا جا سکے۔

#### 2. ایک EC2 انسٹینس کا آغاز

1.  **EC2 ڈیش بورڈ پر جائیں:** AWS مینجمنٹ کنسول میں، "EC2" تلاش کریں اور اسے منتخب کریں۔
2.  **انسٹینس لانچ کریں:** "Launch instances" پر کلک کریں۔
3.  **ایک ایمیزون مشین امیج (AMI) منتخب کریں:** NVIDIA ڈیپ لرننگ AMI یا Ubuntu سرور AMI تلاش کریں۔ NVIDIA AMIs پیش کرتا ہے جو CUDA، cuDNN، اور عام ڈیپ لرننگ فریم ورک کے ساتھ پہلے سے کنفیگرڈ ہیں، جو سیٹ اپ کے وقت کو بچا سکتے ہیں۔ اگر ایک معیاری Ubuntu AMI کا انتخاب کرتے ہیں، تو آپ کو NVIDIA ڈرائیورز، CUDA، اور دیگر ٹولز کو دستی طور پر انسٹال کرنے کی ضرورت ہوگی۔
4.  **انسٹینس کی قسم منتخب کریں:** `g5.2xlarge` منتخب کریں۔
5.  **انسٹینس کی تفصیلات کنفیگر کریں:**
    *   **نیٹ ورک:** ایک نیا VPC بنائیں یا ایک موجودہ استعمال کریں۔ یقینی بنائیں کہ اس کے پاس انٹرنیٹ تک رسائی کے لئے ایک پبلک IP ایڈریس ہے۔
    *   **اسٹوریج:** کافی اسٹوریج شامل کریں، ترجیحاً ایک SSD (gp3 یا io2) کم از کم 100-200 GB کے ساتھ آپ کے OS، ٹولز، اور ڈیٹا سیٹس کے لئے۔
    *   **سیکیورٹی گروپ:** ایک نیا سیکیورٹی گروپ بنائیں۔ اپنے IP ایڈریس سے SSH رسائی (پورٹ 22) کی اجازت دیں۔ اگر آپ ایک گرافیکل ڈیسک ٹاپ ماحول یا مخصوص سروسز چلانے کا ارادہ رکھتے ہیں، تو متعلقہ پورٹس کھولیں (مثلاً، VNC پورٹس، کسٹم ایپلیکیشن پورٹس)۔
6.  **جائزہ لیں اور لانچ کریں:** اپنی کنفیگریشن کا جائزہ لیں اور انسٹینس لانچ کریں۔ آپ کو ایک نئی کی جوڑی بنانے یا ایک موجودہ استعمال کرنے کا اشارہ کیا جائے گا۔ `.pem` فائل ڈاؤن لوڈ کریں اور اسے محفوظ رکھیں؛ آپ کو اپنے انسٹینس میں SSH کرنے کے لئے اس کی ضرورت ہوگی۔

#### 3. اپنے انسٹینس سے SSH کے ذریعے جڑنا

1.  **کی جوڑی کی اجازتیں تبدیل کریں:** اپنے مقامی مشین پر، ایک ٹرمینل کھولیں اور `chmod 400 your-key-pair.pem` چلائیں تاکہ آپ کی کی فائل کے لئے مناسب اجازتیں مقرر کی جا سکیں۔
2.  **SSH کمانڈ:** اپنے انسٹینس کے پبلک IP ایڈریس یا DNS نام کا استعمال کرتے ہوئے جڑیں:
    ```bash
    ssh -i your-key-pair.pem ubuntu@<your-instance-public-ip>
    ```
    (اگر آپ نے ایمیزون لینکس AMI کا انتخاب کیا ہے تو `ubuntu` کو `ec2-user` سے تبدیل کریں۔)

#### 4. لانچ کے بعد سیٹ اپ (اگر ایک بنیادی Ubuntu AMI استعمال کر رہے ہیں)

اگر آپ نے ایک معیاری Ubuntu AMI کا انتخاب کیا ہے بجائے ایک NVIDIA ڈیپ لرننگ AMI کے، تو آپ کو NVIDIA ڈرائیورز اور CUDA انسٹال کرنے کی ضرورت ہوگی۔ (اگر ایک NVIDIA AMI استعمال کر رہے ہیں، تو یہ مراحل بڑی حد تک پہلے سے کنفیگرڈ ہیں، حالانکہ اپ ڈیٹس کی ضرورت ہو سکتی ہے۔)

1.  **سسٹم کو اپ ڈیٹ کریں:**
    ```bash
    sudo apt update && sudo apt upgrade -y
    ```
2.  **NVIDIA ڈرائیورز انسٹال کریں:** Ubuntu پر ڈرائیورز انسٹال کرنے کے لئے NVIDIA کی سرکاری دستاویزات کی پیروی کریں۔ اس میں عام طور پر NVIDIA ریپوزٹریز شامل کرنا اور `nvidia-driver-XXX` انسٹال کرنا شامل ہوتا ہے۔
3.  **CUDA ٹول کٹ انسٹال کریں:** NVIDIA کی ویب سائٹ سے CUDA ٹول کٹ ڈاؤن لوڈ اور انسٹال کریں۔ یقینی بنائیں کہ ورژن آپ کے انسٹال کردہ ڈرائیورز اور مطلوبہ AI فریم ورک کے ساتھ مطابقت رکھتا ہے۔
4.  **cuDNN انسٹال کریں:** cuDNN (CUDA ڈیپ نیورل نیٹ ورک لائبریری) ڈیپ لرننگ کو تیز کرنے کے لئے ضروری ہے۔ NVIDIA کی ہدایات کے مطابق اسے انسٹال کریں۔
5.  **AI فریم ورک انسٹال کریں:** TensorFlow، PyTorch، اور دیگر ضروری لائبریریاں انسٹال کریں۔ Python ماحول اور انحصارات کو منظم کرنے کے لئے Miniconda یا Anaconda کا استعمال کرنا انتہائی سفارش کی جاتی ہے۔
    ```bash
    wget https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh
    bash Miniconda3-latest-Linux-x86_64.sh
    source ~/.bashrc
    conda create -n robotics python=3.10
    conda activate robotics
    pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118 # Example for PyTorch
    ```

#### 5. ROS 2 اور دیگر روبوٹکس ٹولز انسٹال کرنا

Ubuntu 22.04 پر اپنے منتخب کردہ ڈسٹری بیوشن (مثلاً، Humble, Iron) کے لئے سرکاری ROS 2 دستاویزات کی پیروی کریں۔ اس میں عام طور پر ROS ریپوزٹریز شامل کرنا، بنیادی پیکجز انسٹال کرنا، اور اپنے ماحول کو ترتیب دینا شامل ہوتا ہے۔

*   **ROS 2 انسٹالیشن:**
    ```bash
    sudo apt install software-properties-common
    sudo add-apt-repository universe
    sudo apt update && sudo apt install curl -y
    sudo curl -sSL https://raw.githubusercontent.com/ros/rosdistro/master/ros.key -o /usr/share/keyrings/ros-archive-keyring.gpg
    echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/ros-archive-keyring.gpg] http://packages.ros.org/ros2/ubuntu $(. /etc/os-release && echo $UBUNTU_CODENAME) main" | sudo tee /etc/apt/sources.list.d/ros2.list > /dev/null
    sudo apt update
    sudo apt upgrade -y
    sudo apt install ros-humble-desktop -y # Or your desired distribution
    ```
*   **ترقیاتی ٹولز:** `colcon-common-extensions`, `git`, `build-essential`, `cmake`, اور دیگر ٹولز انسٹال کریں جو ROS 2 ورک اسپیسز کو مرتب کرنے کے لئے درکار ہیں۔

### ریموٹ ڈیسک ٹاپ (اختیاری)

گرافیکل انٹرفیس کے لئے، آپ VNC یا NoMachine کا استعمال کرتے ہوئے ایک ریموٹ ڈیسک ٹاپ ماحول ترتیب دے سکتے ہیں۔ یہ آپ کو اپنے کلاؤڈ انسٹینس کے ڈیسک ٹاپ کے ساتھ ایسے تعامل کرنے کی اجازت دیتا ہے جیسے یہ مقامی ہو۔

*   **ڈیسک ٹاپ ماحول انسٹال کریں:**
    ```bash
    sudo apt install ubuntu-desktop # Or xfce4 for a lighter environment
    ```
*   **VNC سرور انسٹال اور کنفیگر کریں:** `tightvncserver` یا `x11vnc` انسٹال کریں اور اسے بوٹ پر شروع کرنے کے لئے کنفیگر کریں۔ یاد رکھیں کہ اپنے AWS سیکیورٹی گروپ میں VNC پورٹ (مثلاً، 5901) کھولیں۔

ان مراحل کی پیروی کرتے ہوئے، آپ AWS پر ایک طاقتور اور لچکدار کلاؤڈ لیب ماحول قائم کریں گے، جو آپ کی فزیکل AI اور ہیومینائیڈ روبوٹکس کی ترقی کو تیز کرنے کے لئے تیار ہے۔
