# ضمیمہ A: کلاؤڈ لیب سیٹ اپ

یہ ضمیمہ AWS g5.2xlarge انسٹینسز پر توجہ مرکوز کرتے ہوئے ایک مضبوط کلاؤڈ بیسڈ لیب ماحول کے سیٹ اپ کے لئے تفصیلی گائیڈز فراہم کرتا ہے۔ فزیکل AI اور ہیومینائیڈ روبوٹکس کے شعبے میں، مقامی ہارڈ ویئر کی حدود اکثر بڑے ماڈلز کی تربیت، پیچیدہ سمولیشنز چلانے، یا اعلیٰ معیار کے سینسری ڈیٹا کے تجربات کے لئے رکاوٹ بن سکتی ہیں۔ کلاؤڈ بیسڈ ورک سٹیشنز ایک قابل توسیع اور طاقتور متبادل پیش کرتے ہیں، جو جدید GPUs اور وافر کمپیوٹیشنل وسائل تک رسائی فراہم کرتے ہیں۔ یہ ہدایات آپ کو ایک طاقتور ریموٹ ورک سٹیشن کو ترتیب دینے میں مدد کریں گی جو آپ کے مقامی ترقیاتی فلو کے ساتھ بغیر کسی رکاوٹ کے ضم ہو سکتا ہے، جس سے آپ کو زیادہ مطالبہ کرنے والے AI اور روبوٹکس پروجیکٹس کو بغیر کسی بڑی ابتدائی ہارڈ ویئر سرمایہ کاری کے نمٹنے کی اجازت ملتی ہے۔

### کلاؤڈ لیب ماحول کیوں منتخب کریں؟

فزیکل AI کی ترقی کے لئے کلاؤڈ لیبز کئی قائل کرنے والے فوائد پیش کرتے ہیں:

*   **قابل توسیعیت:** اپنے پروجیکٹ کی ضروریات کے مطابق اپنے کمپیوٹیشنل وسائل کو آسانی سے بڑھائیں یا کم کریں، ترقی کے لئے ایک واحد GPU انسٹینس سے لے کر تقسیم شدہ تربیت کے لئے متعدد GPU انسٹینسز تک۔
*   **لاگت کی تاثیر:** پے-ایز-یو-گو ماڈلز کا مطلب ہے کہ آپ صرف ان وسائل کے لئے ادائیگی کرتے ہیں جو آپ استعمال کرتے ہیں، ہارڈ ویئر میں بڑے ابتدائی سرمایہ کاری سے بچتے ہیں جو ممکنہ طور پر متروک ہو سکتے ہیں۔
*   **رسائی:** انٹرنیٹ کنکشن کے ساتھ کہیں سے بھی اپنے طاقتور ترقیاتی ماحول تک رسائی حاصل کریں، لچکدار کام کے انتظامات کو فروغ دیں۔
*   **پری-کنفیگرڈ ماحول:** بہت سے کلاؤڈ فراہم کنندگان مشہور AI اور روبوٹکس فریم ورکس (CUDA، cuDNN، TensorFlow، PyTorch، ROS) کے ساتھ پہلے سے تیار شدہ امیجز پیش کرتے ہیں، جو سیٹ اپ کے وقت کو نمایاں طور پر کم کرتے ہیں۔
*   **تعاون:** کلاؤڈ ماحول ٹیم کے اراکین کے درمیان آسان تعاون کی سہولت فراہم کرتے ہیں، کیونکہ ہر کوئی ایک ہی طاقتور انفراسٹرکچر پر مستقل ترتیب کے ساتھ کام کر سکتا ہے۔

### AWS g5.2xlarge انسٹینس: ایک تجویز کردہ انتخاب

AWS g5.2xlarge انسٹینس ایک کلاؤڈ بیسڈ فزیکل AI لیب کے لئے ایک بہترین انتخاب ہے، اس کی طاقتور GPU صلاحیتوں اور لاگت کی تاثیر کے توازن کی وجہ سے۔ اس میں شامل ہیں:

*   **GPU:** ایک NVIDIA A10G ٹینسر کور GPU، جو ڈیپ لرننگ تربیت، انفرینس، اور کمپیوٹ-انٹینسیو سمولیشنز کے لئے نمایاں تیزی فراہم کرتا ہے۔
*   **vCPUs:** 8 ورچوئل CPUs، جو عمومی کاموں اور ڈیٹا آرکیسٹریشن کے لئے وافر پروسیسنگ پاور فراہم کرتے ہیں۔
*   **میموری:** 32 GiB RAM، درمیانے سے بڑے پیمانے کے AI ماڈلز اور ڈیٹا سیٹس کے لئے موزوں۔
*   **نیٹ ورک کی کارکردگی:** 10 گیگا بٹ تک نیٹ ورک بینڈوڈتھ، اسٹوریج سے اور اسٹوریج تک تیز ڈیٹا ٹرانسفر کو یقینی بناتی ہے۔
*   **اسٹوریج:** EBS بیکڈ اسٹوریج، جسے I/O مطالبات کو پورا کرنے کے لئے ہائی پرفارمنس SSDs کے لئے ترتیب دیا جا سکتا ہے۔

### مرحلہ وار سیٹ اپ گائیڈ

#### 1. AWS اکاؤنٹ سیٹ اپ اور ریجن کا انتخاب

اگر آپ کے پاس نہیں ہے تو، ایک AWS اکاؤنٹ بنائیں۔ یقینی بنائیں کہ آپ ایک ایسا ریجن منتخب کرتے ہیں جو g5 انسٹینسز پیش کرتا ہے اور جغرافیائی طور پر آپ کے قریب یا آپ کے ڈیٹا ذرائع کے قریب ہے تاکہ لیٹنسی کو کم کیا جا سکے۔

#### 2. ایک EC2 انسٹینس کا آغاز

1.  **EC2 ڈیش بورڈ پر جائیں:** AWS مینجمنٹ کنسول میں، "EC2" تلاش کریں اور اسے منتخب کریں۔
2.  **انسٹینس لانچ کریں:** "Launch instances" پر کلک کریں۔
3.  **ایک ایمیزون مشین امیج (AMI) منتخب کریں:** NVIDIA ڈیپ لرننگ AMI یا Ubuntu سرور AMI تلاش کریں۔ NVIDIA AMIs پیش کرتا ہے جو CUDA، cuDNN، اور عام ڈیپ لرننگ فریم ورکس کے ساتھ پہلے سے ترتیب شدہ ہیں، جو سیٹ اپ کے وقت کو نمایاں طور پر بچا سکتے ہیں۔ اگر آپ ایک معیاری Ubuntu AMI منتخب کرتے ہیں، تو آپ کو NVIDIA ڈرائیورز، CUDA، اور دیگر ٹولز کو دستی طور پر انسٹال کرنے کی ضرورت ہوگی۔
4.  **انسٹینس کی قسم منتخب کریں:** `g5.2xlarge` منتخب کریں۔
5.  **انسٹینس کی تفصیلات ترتیب دیں:**
    *   **نیٹ ورک:** ایک نیا VPC بنائیں یا موجودہ کو استعمال کریں۔ یقینی بنائیں کہ اس میں انٹرنیٹ تک رسائی کے لئے ایک عوامی IP ایڈریس ہے۔
    *   **اسٹوریج:** کافی اسٹوریج شامل کریں، ترجیحاً SSD (gp3 یا io2) کے ساتھ کم از کم 100-200 GB آپ کے OS، ٹولز، اور ڈیٹا سیٹس کے لئے۔
    *   **سیکیورٹی گروپ:** ایک نیا سیکیورٹی گروپ بنائیں۔ اپنے IP ایڈریس سے SSH رسائی (پورٹ 22) کی اجازت دیں۔ اگر آپ گرافیکل ڈیسک ٹاپ ماحول یا مخصوص سروسز چلانے کا ارادہ رکھتے ہیں، تو متعلقہ پورٹس کھولیں (مثلاً VNC پورٹس، کسٹم ایپلیکیشن پورٹس)۔
6.  **جائزہ اور لانچ:** اپنی ترتیب کا جائزہ لیں اور انسٹینس کو لانچ کریں۔ آپ کو ایک نئی کیی جوڑی بنانے یا موجودہ کو استعمال کرنے کا اشارہ دیا جائے گا۔ `.pem` فائل ڈاؤن لوڈ کریں اور اسے محفوظ رکھیں؛ آپ کو اپنے انسٹینس میں SSH کرنے کے لئے اس کی ضرورت ہوگی۔

#### 3. SSH کے ذریعے اپنے انسٹینس سے جڑنا

1.  **کیی جوڑی کی اجازتیں تبدیل کریں:** اپنے مقامی مشین پر، ایک ٹرمینل کھولیں اور اپنے کیی فائل کے لئے مناسب اجازتیں ترتیب دینے کے لئے `chmod 400 your-key-pair.pem` چلائیں۔
2.  **SSH کمانڈ:** اپنے انسٹینس کے عوامی IP ایڈریس یا DNS نام کا استعمال کرتے ہوئے جڑیں:
    ```bash
    ssh -i your-key-pair.pem ubuntu@<your-instance-public-ip>
    ```
    (اگر آپ نے ایمیزون لینکس AMI منتخب کیا ہے تو `ubuntu` کو `ec2-user` سے تبدیل کریں۔)

#### 4. پوسٹ-لانچ سیٹ اپ (اگر بنیادی Ubuntu AMI استعمال کر رہے ہیں)

اگر آپ نے NVIDIA ڈیپ لرننگ AMI کے بجائے ایک معیاری Ubuntu AMI کا انتخاب کیا ہے، تو آپ کو NVIDIA ڈرائیورز اور CUDA انسٹال کرنے کی ضرورت ہوگی۔ (اگر آپ NVIDIA AMI استعمال کر رہے ہیں، تو یہ مراحل زیادہ تر پہلے سے ترتیب شدہ ہیں، حالانکہ اپ ڈیٹس کی ضرورت ہو سکتی ہے۔)

1.  **سسٹم کو اپ ڈیٹ کریں:**
    ```bash
    sudo apt update && sudo apt upgrade -y
    ```
2.  **NVIDIA ڈرائیورز انسٹال کریں:** Ubuntu پر ڈرائیورز انسٹال کرنے کے لئے NVIDIA کی سرکاری دستاویزات کی پیروی کریں۔ اس میں عام طور پر NVIDIA ریپوزٹریز شامل کرنا اور `nvidia-driver-XXX` انسٹال کرنا شامل ہوتا ہے۔
3.  **CUDA ٹول کٹ انسٹال کریں:** NVIDIA کی ویب سائٹ سے CUDA ٹول کٹ ڈاؤن لوڈ اور انسٹال کریں۔ یقینی بنائیں کہ ورژن آپ کے نصب شدہ ڈرائیورز اور مطلوبہ AI فریم ورکس کے ساتھ مطابقت رکھتا ہے۔
4.  **cuDNN انسٹال کریں:** cuDNN (CUDA ڈیپ نیورل نیٹ ورک لائبریری) ڈیپ لرننگ کو تیز کرنے کے لئے ضروری ہے۔ NVIDIA کی ہدایات کے مطابق اسے انسٹال کریں۔
5.  **AI فریم ورکس انسٹال کریں:** TensorFlow، PyTorch، اور دیگر ضروری لائبریریاں انسٹال کریں۔ Python ماحول اور انحصار کو منظم کرنے کے لئے Miniconda یا Anaconda کا استعمال انتہائی تجویز کیا جاتا ہے۔
    ```bash
    wget https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh
    bash Miniconda3-latest-Linux-x86_64.sh
    source ~/.bashrc
    conda create -n robotics python=3.10
    conda activate robotics
    pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118 # Example for PyTorch
    ```

#### 5. ROS 2 اور دیگر روبوٹکس ٹولز انسٹال کرنا

Ubuntu 22.04 پر اپنے منتخب کردہ ڈسٹریبیوشن (مثلاً، Humble, Iron) کو انسٹال کرنے کے لئے سرکاری ROS 2 دستاویزات کی پیروی کریں۔ اس میں عام طور پر ROS ریپوزٹریز شامل کرنا، بنیادی پیکجز انسٹال کرنا، اور اپنے ماحول کو ترتیب دینا شامل ہوتا ہے۔

*   **ROS 2 انسٹالیشن:**
    ```bash
    sudo apt install software-properties-common
    sudo add-apt-repository universe
    sudo apt update && sudo apt install curl -y
    sudo curl -sSL https://raw.githubusercontent.com/ros/rosdistro/master/ros.key -o /usr/share/keyrings/ros-archive-keyring.gpg
    echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/ros-archive-keyring.gpg] http://packages.ros.org/ros2/ubuntu $(. /etc/os-release && echo $UBUNTU_CODENAME) main" | sudo tee /etc/apt/sources.list.d/ros2.list > /dev/null
    sudo apt update
    sudo apt upgrade -y
    sudo apt install ros-humble-desktop -y # Or your desired distribution
    ```
*   **ترقیاتی ٹولز:** `colcon-common-extensions`, `git`, `build-essential`, `cmake`, اور دیگر ٹولز انسٹال کریں جو ROS 2 ورک اسپیسز کو مرتب کرنے کے لئے ضروری ہیں۔

### ریموٹ ڈیسک ٹاپ (اختیاری)

گرافیکل انٹرفیس کے لئے، آپ VNC یا NoMachine کا استعمال کرتے ہوئے ریموٹ ڈیسک ٹاپ ماحول ترتیب دے سکتے ہیں۔ یہ آپ کو اپنے کلاؤڈ انسٹینس کے ڈیسک ٹاپ کے ساتھ ایسے تعامل کرنے کی اجازت دیتا ہے جیسے یہ مقامی ہو۔

*   **ڈیسک ٹاپ ماحول انسٹال کریں:**
    ```bash
    sudo apt install ubuntu-desktop # Or xfce4 for a lighter environment
    ```
*   **VNC سرور انسٹال اور ترتیب دیں:** `tightvncserver` یا `x11vnc` انسٹال کریں اور اسے بوٹ پر شروع کرنے کے لئے ترتیب دیں۔ یاد رکھیں کہ اپنے AWS سیکیورٹی گروپ میں VNC پورٹ (مثلاً، 5901) کھولیں۔

ان مراحل کی پیروی کرتے ہوئے، آپ AWS پر ایک طاقتور اور لچکدار کلاؤڈ لیب ماحول قائم کریں گے، جو آپ کے فزیکل AI اور ہیومینائیڈ روبوٹکس کی ترقی کو تیز کرنے کے لئے تیار ہے۔
