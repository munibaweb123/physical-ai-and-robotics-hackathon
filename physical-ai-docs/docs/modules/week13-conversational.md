# Week 13: Conversational Robotics

## Topics
- **Generative AI in Robotics**: Beyond scripted responses.
- **LLM Integration**: Connecting GPT-4 to ROS 2 nodes.
- **Multi-modal Interaction**:
  - **Speech**: Whisper (ASR) and TTS.
  - **Vision**: Vision-Language-Action (VLA) models.
- **Voice-to-Action**: Translating "Pick up the apple" to coordinate goals.

## Lab
- Build a ROS 2 node that queries an OpenAI API.
- Execute a robot action based on natural language prompt.
