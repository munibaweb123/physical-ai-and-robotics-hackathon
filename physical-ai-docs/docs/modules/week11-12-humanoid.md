# Week 11-12: Humanoid Development

## Topics
- **Kinematics**: Forward vs Inverse Kinematics (IK).

- **Locomotion**: Bipedal walking gaits.
- **Manipulation**: Grasping with anthropomorphic hands.

## Lab
- Control a simulated biped in Isaac Sim.
