# Control Basics

## PID Controller
A PID controller is a type of feedback control system widely used in industrial control applications. PID stands for Proportional, Integral, and Derivative, which are the three terms used to calculate the control output. The controller continuously calculates an error value as the difference between a desired setpoint and a measured process variable, and applies a correction based on proportional, integral, and derivative terms, hence the name. The proportional term produces an output value that is proportional to the current error value, the integral term accounts for past values of the error, and the derivative term predicts future error based on its rate of change. This combination helps the system to reach the desired setpoint efficiently and maintain stability.

## Feedback
Feedback in control systems works by measuring the output of a system and comparing it to a desired setpoint. This comparison helps determine any deviation from the setpoint, allowing the system to make necessary adjustments to minimize the error and achieve the desired output.
