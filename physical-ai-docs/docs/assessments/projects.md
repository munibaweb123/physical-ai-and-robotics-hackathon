# Assessments & Capstone

## Grading Breakdown
- **ROS 2 Project**: 20%
- **Sim-to-Real Lab**: 20%
- **Perception Pipeline**: 20%
- **Capstone Project**: 40%

## Capstone: Simulated Humanoid with Conversational AI

**Objective**: Demonstrate a full "Physical AI" stack in simulation.

**Requirements**:
1. **Environment**: Custom Isaac Sim scene (e.g., a kitchen).
2. **Robot**: Humanoid (e.g., Unitree G1 or custom URDF).
3. **Interaction**:
   - User speaks a command (simulated text or audio).
   - Robot acknowledges via TTS.
   - Robot plans path and executes manipulation task.
4. **Documentation**: A full README and video demo.
